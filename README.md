## Descripción del proyecto

TIENDA_PRO es un sistema de gestión de indumentaria
desarrollado en PSeInt.

Permite administrar productos, usuarios, proveedores,
stock y ventas mediante menús interactivos.

## Funcionalidades

- Registro de usuarios.
- Acceso mediante usuarios y contraseñas.
- Menús para diferentes tipos de usuarios.
- Gestión de productos (CRUD).
- Administración de proveedores.
- Control de stock por talles.
- Registro de ventas.
- Cálculo de precios y descuentos.

## Herramientas utilizadas

- PSeInt
- GitHub

## Conceptos de programación aplicados

- Variables y constantes.
- Vectores y matrices.
- Condicionales Si y Segun.
- Ciclos Para y Repetir.
- Funciones y subprocesos.
- Validaciones de datos.

## Cómo ejecutar el programa

1. Descargar el archivo .psc del repositorio.
2. Abrir PSeInt.
3. Abrir el archivo descargado.
4. Ejecutar el algoritmo.
5. Seleccionar una opción del menú.

## Objetivo

Aplicar los conocimientos adquiridos en Laboratorio
mediante el desarrollo de un sistema de gestión
de indumentaria.

## Aclaración

Los datos se mantienen en memoria durante la ejecución.
Esta versión no utiliza archivos para guardar información.
